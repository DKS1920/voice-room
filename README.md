# ویس‌روم — Voice + Screen Share

سایت ویس گروهی با اشتراک صفحه، بدون نیاز به نصب. ساخته شده با WebRTC + PeerJS.

## ویژگی‌ها
- ویس با کیفیت، میوت/دیفن، تشخیص صحبت کردن
- اشتراک صفحه (Screen Share) برای همه اعضا
- چت متنی + لیست اعضا
- Mesh خودکار — همه به شناسه سازنده وصل می‌شوند

## اجرا لوکال
```bash
npx http-server . -p 8000
# باز کن: http://localhost:8000
```
