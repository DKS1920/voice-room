    راهنمای استفاده

    1. نامت را وارد کن و ساخت اتاق را بزن. یک شناسه مثل v-xxxx ساخته می‌شود.
    2. لینک یا شناسه را برای دوستانت بفرست.
    3. آنها شناسه را در بخش ورود به اتاق وارد کنند.
    4. بعد از اتصال، میکروفون به صورت خودکار روشن است. با دکمه‌ها میوت یا اشتراک صفحه را فعال کن.
    5. برای گروه 3+ نفره: همه به شناسه سازنده وصل شوند — سیستم به صورت Mesh همه را به هم وصل می‌کند.

    این نسخه از PeerJS Cloud (رایگان) برای سیگنالینگ استفاده می‌کند. برای استفاده سازمانی می‌توانی سرور PeerJS اختصاصی جایگزین کنی.
